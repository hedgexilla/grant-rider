# Granted Copilot: setup guide

No coding needed. Setup takes about 3 minutes.

## What you need
- Google Chrome
- The Granted Copilot install link Sharif sent you
- The dashboard password (ask Sharif)

## Install the extension (one time)
1. Open the install link in Chrome and click **Add to Chrome**, then **Add extension**.
2. Click the puzzle-piece icon in Chrome's toolbar, then the pin next to **Granted Copilot**
   so its icon stays visible.

## Connect it to the dashboard (one time)
1. Click the Granted Copilot icon.
2. At the bottom, check the address says `https://grant-rider.vercel.app`.
3. Type the dashboard password, then click **↻ Sync Dashboard**.
   You should see "Synced latest Founder Profile".

## Apply to a grant
1. Open https://grant-rider.vercel.app and sign in with username `abena` and the password.
2. Find a grant and click **Apply with Autofill**. The grant's own site opens in a new tab.
3. The extension fills the form. If the site asks you to sign in first, sign in, open the
   form, then click the green **Autofill Grant** button in the bottom-right corner.
4. **Read every answer.** Fill anything left blank (EIN, phone, email, amount) and correct
   anything that's wrong.
5. Press the grant site's own **Submit** button. The extension never submits for you.

## Updates
Chrome installs updates automatically. You don't need to do anything.
